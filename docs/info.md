# SKY130 Instrumentation Amplifier

## Overview

This project implements a custom analog instrumentation amplifier
using the SkyWater SKY130A process.

The design includes:
- A two-op-amp instrumentation amplifier architecture
- An integrated bandgap voltage reference
- External gain-setting resistor terminals
- An internal reference midpoint generated by a resistor divider
- A Tiny Tapeout-compatible 2x2 analog layout

This project was developed for ECE 5120 as a VLSI design
and verification exercise. Physical fabrication is not planned.

## Circuit Architecture

The instrumentation amplifier accepts differential input signals
at Vp and Vn and produces an output at Vout.

Rgp and Rgn provide terminals for the external gain-setting
resistor. The internal bandgap generates Vref, which is also
available on an analog pin.

An internal resistor divider generates Vmid from the analog
supply and ground. Its loaded operating voltage requires
simulation verification.

## Analog Pinout

| Pin | Signal | Function |
|-----|--------|----------|
| ua[0] | Vout | Amplifier output |
| ua[1] | Rgp | Positive gain-resistor terminal |
| ua[2] | Vp | Noninverting input |
| ua[3] | Rgn | Negative gain-resistor terminal |
| ua[4] | Vn | Inverting input |
| ua[5] | Vref | Bandgap reference output |

## Power and Interface

- VAPWR: 3.3 V analog supply
- VGND: Ground
- VDPWR: Unused digital supply connection
- Analog pins used: 6
- Tile size: 2x2
- Layout dimensions: 319.240 x 225.760 micrometers
- Top module: tt_um_niclemmons_instamp

The unused digital output and output-enable signals are tied
to ground in the physical layout. Digital inputs are unused.

## Design Tools

- Xschem: Schematic capture
- ngspice: Circuit simulation
- Magic: Physical layout and DRC
- Netgen: Layout-versus-schematic comparison
- KLayout: Independent GDS inspection and DRC
- SKY130A PDK: Device models and layout design rules

## Verification

The Magic layout passes DRC with zero errors.

The original complete circuit passed Netgen LVS. After subsequent
routing modifications, a diagnostic netlist with normalized ground
pin aliases also passed LVS. A final check of the unmodified
extraction is still required.

The exported GDS generates three HVI hierarchy warnings in Magic.
Independent KLayout checks have also reported DRC markers.
These results are retained for documentation and have not been
cleared for fabrication.
